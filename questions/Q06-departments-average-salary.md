
# Q06 — Departments with Average Salary Above 60,000

## Problem Statement

Calculate average salary per department and return only departments whose average is strictly greater than 60,000.

## Table Schema

**Table: `q06_employees`**

| employee_id | department | salary |
|---:|---|---:|
| 1 | IT | 80000 |
| 2 | IT | 70000 |
| 3 | HR | 50000 |
| 4 | HR | 55000 |
| 5 | Finance | 90000 |
| 6 | Finance | 70000 |

## Expected Output

| department | avg_salary |
|---|---:|
| IT | 75000.00 |
| Finance | 80000.00 |
